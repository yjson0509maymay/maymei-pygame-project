혈관 속을 누비며 떨어지는 음식 아이템을 받아 **혈관 정화도**를 관리하는 2D 아케이드 게임입니다.
좋은 음식은 혈관을 깨끗하게, 나쁜 음식은 더럽게 만들며, 1분을 버티거나 정화도 100%를 달성하면 승리합니다.

> **개발 언어**: Python · **주요 라이브러리**: pygame, numpy
> Python 프로그래밍(기초) 수업 미니 프로젝트 · 2025.02

## 🎮 게임 소개

기름 낀 혈관(시작 정화도 35%)을 청소하는 클린업 미션입니다. 위에서 떨어지는 아이템을 좌우로 움직여 받아내며, 혈관 벽은 정화도에 따라 좁아지거나 넓어집니다.

| 아이템 | 효과 |
|--------|------|
| 🥦 브로콜리 (초록) | 정화도 +7 (Good) |
| 🍔 햄버거 (갈색) | 정화도 −12 (Bad) |
| 👟 운동화 (파랑) | 약 2초간 무적 + 햄버거 무효화 (Fever 필살기) |

**승리 조건**: 정화도 100% 달성 **또는** 60초 생존
**패배 조건**: 정화도 0% 도달

조작: `←` `→` 좌우 이동 · `R` 재시작 · `ESC` 종료

## 🛠️ 사용 기술 및 기능

### 핵심 라이브러리
- **pygame** — 게임 화면 렌더링, 이벤트 처리, 메인 루프, 폰트, 충돌 판정
- **numpy** — 배경 이미지를 배열로 변환해 픽셀 단위로 가공 (크로스페이드 블렌딩)
- **math / random / os** — 사인파 계산, 아이템 랜덤 생성, 파일 경로 처리

### 구현한 기능

**1. 무한 스크롤 배경 (이음새 없는 세로 루프)**
- `make_vertical_loop()` — 배경 이미지를 위아래로 이어 붙이고, 겹치는 구간을 numpy로 **크로스페이드(점진적 알파 블렌딩)** 처리해 이음새가 보이지 않는 무한 루프 이미지를 생성
- `scale_cover()` — 화면 비율에 맞춰 이미지를 잘리지 않게 꽉 채우는 cover 스케일링
- `draw_scrolling_bg()` — 배경을 위→아래로 흐르게 해 전진하는 느낌 연출

**2. 구불구불 움직이는 혈관 벽**
- `corridor_edges()` — **사인 함수**로 시간에 따라 출렁이는 좌우 벽 경계를 실시간 계산
- `draw_wavy_walls()` — 계산된 경계를 폴리곤으로 그리고, `SRCALPHA` 반투명 서피스로 배경이 비치도록 처리
- `draw_vessel()` — 정화도가 낮을수록 벽이 좁아지도록 offset을 **선형 보간(lerp)** 으로 부드럽게 변화

**3. 게임 시스템**
- **상태 관리**: `PLAY / WIN / LOSE` 상태에 따라 화면과 입력 분기
- **타이머**: `pygame.time.get_ticks()` 기반 60초 카운트다운
- **아이템 스폰**: 통로 안쪽 랜덤 위치 생성 + 가중치 확률(`random.choices`, 브로콜리/햄버거/운동화 = 45:45:10)
- **충돌 판정**: 플레이어-아이템 거리 계산으로 받기 처리
- **벽 충돌 제한**: 플레이어가 벽 밖으로 나가지 못하게 좌우 범위 클램핑
- **Fever 모드**: 운동화 획득 시 일정 프레임 동안 무적 + 시각 효과

**4. 연출 / UI**
- 한글 폰트(`malgungothic`) 렌더링으로 정화도·남은 시간 표시
- 정화도 20% 이하 시 **빨간 화면 깜빡임** 위험 경고
- 정화도에 따라 플레이어·벽 색상 변화 (위험할수록 어두운 빨강)
- 승/패 화면에 반투명 딤 처리 + 중앙 텍스트 출력
